# Portfolio — Fatima Ezzahraa Nakra

Portfolio personnel réalisé en HTML/CSS/JavaScript et prêt à être publié avec GitHub Pages.

## Publication avec GitHub Pages

1. Crée un compte GitHub si nécessaire.
2. Crée un nouveau dépôt public, par exemple `portfolio`.
3. Décompresse ce dossier et envoie **tous les fichiers** du dossier dans le dépôt.
4. Dans GitHub : **Settings → Pages**.
5. Dans **Build and deployment**, choisis **Deploy from a branch**.
6. Sélectionne la branche `main` et le dossier `/ (root)`, puis **Save**.
7. Après quelques instants, GitHub donnera une adresse du type :
   `https://fati-create.github.io/portfolio/`

## Important pour le CV

Une fois le site publié, ajoute cette URL dans le CV avec un libellé comme :
**Portfolio : https://fati-create.github.io/portfolio/**

Le CV PDF inclus dans ce dossier est également accessible depuis le bouton « Mon CV » du portfolio.
